# Pathfinder AI

## Evidence-Driven Career Decision-Intelligence Platform

Pathfinder AI is an evidence-driven career decision-intelligence platform that helps people evaluate which career directions actually fit their current situation.

Instead of starting with "What career do you want?", Pathfinder starts with the person's:

- skills
- education
- experience
- goals
- timeline
- constraints
- work preferences
- negative preferences

It then compares that profile against structured career and labor-market information and produces explainable, evidence-backed results.

---

## Core Principles

1. Discover before you learn.
2. Evidence before recommendation.
3. Treat negative preferences as meaningful constraints.
4. Reality over motivation.
5. Keep the decision process explainable.

---

## Current Product Direction

The current target is **Version 2**.

V2 is:

- natural-language-first
- multi-domain
- local-first
- evidence-driven
- decision-intelligence oriented
- dashboard-based
- supported by market data
- capable of useful analytics/ML
- supported by an LLM explanation/discussion layer

Pathfinder is **not** a long form-based career questionnaire.

The user should be able to describe their situation naturally, after which Pathfinder extracts relevant information and asks only necessary clarification questions.

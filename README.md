# 🧭 Pathfinder AI

## Evidence-Driven Career Intelligence & Decision Support Platform

Pathfinder AI is an evidence-driven career intelligence platform that helps students and professionals discover careers that truly fit them by comparing their profile against labor market intelligence instead of generic career advice.

## Current Version

Version: 1.0 MVP (Base Level)

## Technology Stack

- Python
- Pandas
- SQLite
- Streamlit
